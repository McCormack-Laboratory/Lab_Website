This page edits People and Publications. (News is written as markdown files in content/news/.) It loads the current content from the data/ folder, lets you add, edit, or remove entries, and then lets you download an updated file. Replace the matching file inside data/ with the one you downloaded, then upload it to the server the same way you upload any other file. This page never sends anything anywhere on its own — nothing is live until you upload the file yourself.
